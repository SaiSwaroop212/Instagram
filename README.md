# Instagram Profile & Feed

A responsive Instagram-style profile and feed built using HTML, CSS, and Vanilla JavaScript.

## About

This project recreates an Instagram-inspired profile page with a responsive 3-column post grid.

It also includes JavaScript features that demonstrate modern frontend concepts such as debouncing, optimistic UI updates, classes and inheritance, functional programming, lazy image loading, infinite scrolling, and the Observer pattern.

## Features

- Instagram-style profile page
- Profile image and user information
- Posts, followers, and following statistics
- Follow button
- Responsive 3-column post grid
- Search with debounce
- Like button with optimistic UI
- Post, Tweet, Comment, and Retweet classes
- Functional feed filtering
- Lazy image loading
- Infinite scrolling
- Loading and error states
- Notification system

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Git
- GitHub
